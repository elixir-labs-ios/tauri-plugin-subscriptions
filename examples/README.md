# Example Usage

This directory contains example code for using the tauri-plugin-subscriptions in your application.

## Files

- `subscription-page.svelte` - Complete subscription page component
- `subscription-store.ts` - Svelte store for managing subscription state
- `subscription-utils.ts` - Utility functions for subscription management

## Integration Steps

1. Copy the relevant files to your project
2. Update product IDs to match your App Store/Play Store configuration
3. Customize the UI to match your app's design
4. Implement backend verification (recommended for production)

## Important Notes

- Always test with sandbox accounts before going live
- Implement server-side receipt validation for security
- Handle all error cases gracefully
- Provide clear messaging to users during purchase flows
